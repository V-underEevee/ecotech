# ecotech
Hi, this is my e-commerce project!
The easyst way to open this project is by downloading the .zip
1. Decompress the zip.
2. Delete the "vendor" folder.
3. Start it with the Laragon Terminal.
4. Enjoy!

If u have never use the laragon terminal before, this is what u have to do:
1. put the decompress project on this path: C:\laragon\www
2. Open the Laragon Terminal.
3. Access the project folder through the path, using the command "cd [folder-name]" till u get to the project folder.
4. Use the command "php artisan serve".
5. Enjoy!

(u can look up for the artisan program urself. don't make me do all the work :P)
